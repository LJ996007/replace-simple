# 性能验证

源码运行方式和打包方式保持不变。本轮优化不增加依赖。

## 实现约定

- 鼠标移动、滚动、窗口尺寸变化的重绘请求合并到约 16 毫秒一帧。状态立即更新，拖动尺寸在松开时提交最终值。
- 文本裁剪缓存最多 128 项，字符测宽缓存最多 4096 项；缩放改变时清理旧测量。超长不换行文本以二分查找确定可见范围。
- 合并区域按 64 行分组索引，不按每个单元格或每行复制合并记录。
- 扫描的表格与条款共用一次自动编号计算。模板完整预览数据在后台读取，窗口复用结果。
- 进度回调只保留最新状态；成功、失败事件单独保存，不合并、不丢弃。
- 工作表快照只读；预览复制需要修改的数据。撤销共享快照，保留最近 100 步。修改此约定时必须同步检查撤销、重做与清空预览。
- 关键词输入停顿 150 毫秒后更新筛选；明确的筛选按钮操作仍立即执行。

## 回归与基准

```powershell
python -m unittest discover -s tests
python -m pytest -q -s tests/test_review_fill_ui.py tests/test_workspace_navigation.py
python outputs/benchmark_canvas.py
```

`test_performance_contracts.py` 检查重复计算、进度队列、缓存上限、拖动最终尺寸和只读快照，避免以机器速度作为测试是否通过的条件。

基准使用 500 行、8 列的合成长文本表格，每组连续重绘 30 次，输出 5 组耗时、中位数、窗口大小和 DPI。比较时保持窗口、DPI、显示器及系统负载一致；结果只代表该场景，不能等同于整套程序的加速比例。
