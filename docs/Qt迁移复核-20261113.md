## 验证结果及边界

环境：Windows、Python 3.14.6、PySide6 6.12.0。本机执行，隔离 Office 样本及应用设置，未操作用户业务文件。

- 初始全套：325 passed、48 subtests passed、1 skipped。
- 最终全套：`PYTHONUTF8=1 QT_QPA_PLATFORM=offscreen python tests/hidden_pytest.py -q -s`，**338 passed、48 subtests passed、1 skipped，48.38s**。跳过项是需要原生 Windows 桌面、使用 SendInput 的 OS 拖放测试，本轮未执行该系统输入路径。两项警告来自既有 Qt 拖放事件构造函数弃用；未掩盖。
- Windows 原生插件专项：100% 与 125% 各 21 passed、2 skipped；150% 的同一业务/主题集合通过，另外加入的 3 项旧布局测试中 1 passed、2 failed。最终状态修复后，三个倍率的截图/状态用例又分别 2 passed。
- 2 项剪贴板跳过：独立 Windows 桌面不能读回系统剪贴板；对应复制、粘贴、撤销、多行内容和越界拒绝在 offscreen Qt 事件测试中通过，不能视为真实系统剪贴板实测。
- 2 项原生布局失败：多步骤下拉框 Enter/Esc 及分隔条 hover 断言。用 `git archive HEAD` 的原始源码在同一独立桌面复跑，仍是 2 failed、1 passed；最小原生 Qt（含主题）Escape 关闭探测通过，但 `QTest.mouseMove()` 后 `underMouse()` 仍为 false。保留原测试，未把断言删掉或改成通过；真实桌面的这两个交互仍须验证。
- 窗口截图覆盖三个主页、来源/目标编辑器、映射核验对话框；窗口包含合成中文长文件名、真实扫描结果和模板库样本。实测 DPR 为 1、1.25、1.5，使用独立进程 `QT_SCALE_FACTOR=0.8/1/1.2`；不是修改 Windows 显示设置，未验证跨显示器切换。150% 时默认大窗请求 1260×860 被桌面约束为 1260×783，按 `geometry.json` 的真实尺寸记录；920×640 实测保持。
- impeccable 机械检查返回 `[]`；该检测不代替 Qt 像素/几何和行为验证。
- 真实桌面驱动：自动审批拒绝 cua-driver 探测，理由是桌面输入保护；本次没有绕过。所有鼠标/键盘检查均说明为 Qt 自动事件，截图来自原生 Qt 在独立测试桌面的渲染。
- 旧格式真实 WPS/Office COM 转换、干净 Windows 机器、真实原生文件选择器操作没有本轮新实测；旧格式单元测试/模拟转换及原件保护仍在全套回归内。

中途遇到并修正的验证配置问题：隔离 APPDATA 令源码子进程暂时找不到用户级 PySide6，补回原 Python 用户依赖路径后启动通过；旧源码副本曾被 pytest 默认递归发现造成同名模块冲突，现置于点目录 `.baseline-reference`，默认完整回归已重新通过。

2026-11-14 提交前复核：工作区仍只有本次 9 个源码、测试、依赖及文档文件。当前 41 个业务模块与成品 PYZ 中的代码对象逐一相等，`main.py` 与成品入口代码对象也相等；两个成品 exe 的 SHA-256 均与上述交付回执一致。三个倍率的截图与几何 JSON、两份成功启动回执仍在。没有新增功能代码改动，因此沿用上述实际验证结果，本次没有声称重新跑过全套回归或真实 GUI。只补充本段交付与提交阶段说明；构建目录、便携包、备份和本地截图按既有忽略规则不入库。
