# replace-simple

批量替换 Office 文本、提取招标项目信息和 Word 表格/条款的离线桌面工具。

当前版本：**v1.2.0**（2026-09-15）。升级注意：空白替换值改为跳过，明确删除使用 `〈删除原文〉`。

完整图文教程见 **[docs/使用教程.md](docs/使用教程.md)**（含界面截图、逐步操作和示例文件）。

## 功能

- 支持 Word `.doc` / `.docx`
- 支持 Excel `.xls` / `.xlsx` / `.xlsm`
- 支持 PowerPoint `.ppt` / `.pptx`
- 新格式直接读写；旧格式通过本机 Microsoft Office 或兼容的 WPS COM 处理，不需要 LibreOffice
- 可在界面中直接录入规则：左侧原文本，右侧替换后文本
- 可导入 Excel 规则表并继续编辑，支持 `.xlsx` / `.xlsm` / `.xls`
- Excel 规则表统一读取第一张工作表的前两列：第一列原文，第二列替换文
- 空白替换值保留为待填写规则，不参与执行；明确删除请填写 `〈删除原文〉`，或用「更多 → 将选中规则设为明确删除」
- 同一原文有不同替换值时阻止执行并提示冲突行；「更多」中可保存规则为 Excel、执行前检查预计输出路径和查看项目信息来源
- 可从招标 Word `.doc` / `.docx` 中读取项目信息，按固定顺序生成 `[项目名称]`、`[项目编号]`、`[标的名称]`、`[采购人名称]` 等占位符替换规则
- 文件内容和文件名都会按规则同步替换
- 多条规则同时生效：在原文上单遍替换，替换结果不会被其它规则再次改写（如「采购人→建设单位」与「单位→公司」并存时，替换结果中的「单位」保持不变）
- Word 替换覆盖正文、表格（含嵌套表格）、文本框、内容控件、超链接、脚注、尾注、批注以及默认/首页/偶数页页眉页脚
- PowerPoint 替换覆盖幻灯片文本、表格、组合形状和备注页
- Excel 数值按底层值转成文本参与替换，不模拟百分比、货币和补零格式（显示为 `25%` 的数值按 `0.25` 匹配）；日期/时间和公式单元格不改写
- 替换结果和 Word 导出的文本按字符串写入 Excel，即使以 `=` 开头也不会成为公式
- Excel 规则表中的日期单元格按 `2026-07-20`（含时间时为 `2026-07-20 09:30:00`）格式读入
- 文件名替换后会自动把 `/`、`\\`、`*` 等 Windows 禁用字符转换为对应全角字符，文档正文保持原样
- 文件名替换后若与源文件同名，直接覆盖源文件；若目标路径已被其他文件占用，则追加 `_1`、`_2` 等后缀
- 替换结果先写入临时副本，保存成功后更新目标；结果窗口显示成功、零命中、失败和真实输出路径，可保存报告及只重试失败文件（沿用该批原规则）
- 已加入待处理列表的文件即使没有匹配任何内容也会输出；零字节文件不解析，直接原样输出
- 可独立提取 Word `.doc` / `.docx` 正文表格到 Excel：每个 Word 生成一个 `_表格.xlsx`，每张表格对应一个工作表，并尽量保留合并单元格
- 「提取信息」窗口会同时扫描正文表格和带符号指标条款：默认识别 `★ # △ ▲`（可在「自定义符号」中增删），符号条款按每个文件的实际章节汇总，勾选章节后输出 `数量序号/符号/详细内容（带序号）` 三列的 `_指标参数.xlsx`
- 可通过主界面右上角「版本」按钮查看当前版本号、发布日期和历次更新说明

## 运行

```bash
pip install -r requirements.txt
python main.py
```

## 打包

```bash
python build.py
```

生成目录位于 `dist/replace-simple/`，可直接运行 `dist/replace-simple/replace-simple.exe`。
脚本会同时生成带版本号、便于分发的 `dist/replace-simple-v<版本号>-portable.zip`。

## 提取信息（Word 表格 / 指标参数）

点击主界面右上角「提取信息」打开独立工具窗口：

1. 添加一个或多个 `.doc` / `.docx` 文件，或选择包含 Word 文件的文件夹。
2. 点击「扫描表格和符号」，根据文件、类型、实际章节和内容预览勾选需要导出的表格或符号章节。
3. 每个表头均可点击打开下拉多选筛选；“筛选结果全选/全不选”按钮可一键切换当前显示结果，也可使用“推荐表格”。
4. 可选择输出目录；未选择时输出到各 Word 文件所在目录。
5. 点击「开始导出」。窗口支持最大化，默认也会尽量显示更多扫描结果和明细内容。

输出文件默认命名为 `原文件名_表格.xlsx`；如果同名文件已存在，会自动追加 `_1`、`_2` 等后缀，避免覆盖。

每个 Word 在一次扫描中只打开解析一次，旧 `.doc` 只转换一次。表格和条款保留为本次扫描快照；导出复用快照并检查源文件大小及修改时间，源文件变化或移除后须重新扫描。

扫描使用「自定义符号…」中的当前符号集，并按每个 Word 实际检测到的完整章节路径汇总；不同文件可以选择不同章节。表格同一单元格内有多条带符号参数时，会按符号条款分别导出，同时保留对应续行和同行序号、名称等上下文。可勾选「条款内容中保留符号」，不勾选则符号只出现在符号列。每个选中符号章节的 Word 生成一个 `原文件名_指标参数.xlsx`。详见使用教程第七章。

## 从招标文件导入项目信息

点击「导入招标文件」选择招标 `.doc` / `.docx`，程序会识别常见字段并填入规则表。读取 `.doc` 需要本机安装 Microsoft Word 或兼容的 WPS Writer。
模板文件中可使用 `[项目名称]`、`[项目编号]`、`[标的名称]`、`[采购人名称]`、`[采购人联系人]`、`[采购人电话]`、`[开标时间]`、`[开标日期]`、`[招标公告日期]`、`[开标地点]`、`[报名人数]`、`[采购人地址]` 等占位符。未识别字段仍会生成空白规则，但不会删除模板占位符。

导入后显示已识别项数；「更多 → 查看项目信息来源」列出直接识别、推断、缺失、冲突及原文位置。多个不同候选值的字段留空，核对后手动填写。引用文本（例如“详见第8章”）不会抢占后面的有效开标值。

## 原文本预设

点击规则区右上角「预设」会打开多选下拉面板。勾选一项或多项后点击「添加所选」，程序会将尚不存在的预设加入规则表的原文本列。

点击「管理预设」可新增、重命名、删除并保存预设；初始内置的 12 个项目字段也可以自由修改。预设保存在当前用户的程序设置中，下次启动时继续使用。

## 分发说明

- 当前打包产物为 Windows 64 位程序，基于 Python 3.11，建议在 Windows 10/11 64 位系统运行。
- 未签名 exe 在新电脑首次运行时可能触发 SmartScreen 提示；这是未签名程序的常见现象，代码签名证书可作为后续根治方案。
- 如果通过网络下载 zip，Windows 可能给文件加 Mark-of-the-Web。遇到拦截时，可先右键 zip → 属性 → 勾选“解除锁定”，再解压运行。
- 建议解压到普通本地目录，例如桌面或文档目录，避免路径过深、网络盘、受保护系统目录。
- 处理 `.doc` / `.xls` / `.ppt` 需要本机安装对应的 Microsoft Office 或兼容 WPS 组件；没有安装时，新格式功能仍可正常使用。
- 程序遇到未捕获异常时，会弹窗提示并写入日志：`%LOCALAPPDATA%\replace-simple\error.log`。

## 开发提示

- 测试：`python -m pytest tests`
- 打包前建议清理旧的 `build/`、`dist/`，`build.py --clean` 已会重新生成 PyInstaller 分析结果。
- 每次发布前在 `app_info.py` 中更新 `APP_VERSION`、`APP_RELEASE_DATE`，并把本次更新说明添加到 `APP_CHANGELOG` 首位。
- `python build.py` 会校验当前版本是否有更新说明，并同步更新窗口标题、软件内版本信息、Windows EXE 文件属性和压缩包文件名。
