# replace-simple

批量替换 Office 文本、提取招标项目信息和 Word 表格/条款的离线桌面工具。

当前版本：**v1.8.0**（2026-10-29）。新增表格排版与行列编辑，优化拖动、扫描和勾选响应，统一弹窗与高清图标。沿用统一绿色版发布，旧格式转换优先调用本机 WPS。

完整图文教程见 **[docs/使用教程.md](docs/使用教程.md)**（含界面截图、逐步操作和示例文件）。

## 功能

- 支持 Word `.doc` / `.docx`
- 支持 Excel `.xls` / `.xlsx` / `.xlsm`
- 支持 PowerPoint `.ppt` / `.pptx`
- 新格式直接读写；旧格式通过本机 Microsoft Office 或兼容的 WPS COM 处理，不需要 LibreOffice
- 可在界面中直接录入规则：左侧原文本，右侧替换后文本
- 可导入 Excel 规则表并继续编辑，支持 `.xlsx` / `.xlsm` / `.xls`
- Excel 规则表统一读取第一张工作表的前两列：第一列原文，第二列替换文
- 空白替换值保留为待填写规则，不参与执行；明确删除请填写 `〈删除原文〉`，或用「更多 → 将选中规则设为明确删除」
- 同一原文有不同替换值时阻止执行并提示冲突行；「更多」中可保存规则为 Excel、执行前检查预计输出路径和查看项目信息来源
- 可从招标 Word `.doc` / `.docx` 中读取项目信息，按固定顺序生成 `[项目名称]`、`[项目编号]`、`[标的名称]`、`[采购人名称]` 等占位符替换规则
- 文件内容和文件名都会按规则同步替换
- 多条规则同时生效：在原文上单遍替换，替换结果不会被其它规则再次改写（如「采购人→建设单位」与「单位→公司」并存时，替换结果中的「单位」保持不变）
- Word 替换覆盖正文、表格（含嵌套表格）、文本框、内容控件、超链接、脚注、尾注、批注以及默认/首页/偶数页页眉页脚
- PowerPoint 替换覆盖幻灯片文本、表格、组合形状和备注页
- Excel 数值按底层值转成文本参与替换，不模拟百分比、货币和补零格式（显示为 `25%` 的数值按 `0.25` 匹配）；日期/时间和公式单元格不改写
- 替换结果和 Word 导出的文本按字符串写入 Excel，即使以 `=` 开头也不会成为公式
- Excel 规则表中的日期单元格按 `2026-07-20`（含时间时为 `2026-07-20 09:30:00`）格式读入
- 文件名替换后会自动把 `/`、`\\`、`*` 等 Windows 禁用字符转换为对应全角字符，文档正文保持原样
- 文件名替换后若与源文件同名，直接覆盖源文件；若目标路径已被其他文件占用，则追加 `_1`、`_2` 等后缀
- 替换结果先写入临时副本，保存成功后更新目标；结果窗口显示成功、零命中、失败和真实输出路径，可保存报告及只重试失败文件（沿用该批原规则）
- 已加入待处理列表的文件即使没有匹配任何内容也会输出；零字节文件不解析，直接原样输出
- 可独立提取 Word `.doc` / `.docx` 正文表格到 Excel：每个 Word 生成一个 `_表格.xlsx`，每张表格对应一个工作表，并尽量保留合并单元格
- 「信息提取」页面会同时扫描正文表格和带符号指标条款：默认识别 `★ # △ ▲`（可在「自定义符号」中增删）。正文条款仍输出 `数量序号/符号/详细内容（带序号）` 三列；采购需求表中的带符号参数按原文分列，设备名称、配置、数量各自一列并保留合并，每条符号参数单独成行，写入 `_指标参数.xlsx`
- 可通过主界面右上角「版本」按钮查看当前版本号、发布日期和历次更新说明

## 运行

```bash
pip install -r requirements.txt
python main.py
```

## 打包

```bash
python build.py
```

生成目录位于 `dist/replace-simple/`，可直接运行 `dist/replace-simple/replace-simple.exe`。
脚本会同时生成带版本号、便于分发的 `dist/replace-simple-v<版本号>-portable.zip`。

## 提取信息（Word 表格 / 指标参数）

点击主窗口顶部的「信息提取」页签切换工作区（旁边为「批量替换」）。默认打开批量替换；首次进入信息提取会自动带入已选择的 Word，之后切换不会重复加入已移除的文件。切换保留当前会话中的文件、扫描结果、筛选和勾选，后台任务继续执行；退出程序后这些提取状态不保留。

1. 添加一个或多个 `.doc` / `.docx` 文件，或选择包含 Word 文件的文件夹。
2. 点击「扫描表格和符号」，根据文件、类型、实际章节和内容预览勾选需要导出的表格或符号章节。
3. 使用顶部文件、章节、类型和关键词筛选；章节和类型支持多选，点击“确定”应用或“取消”保留原筛选。同一条件内匹配任一选项，不同条件同时生效。单击行查看完整内容，复选框或空格负责勾选。指标章节可展开逐条选择，章节显示全选、部分选择或未选状态。
4. “勾选当前结果”“取消当前结果”只影响筛选后的项目；“清空全部”清除所有勾选。“追加推荐表格”保留手动选择。隐藏的已选项会计数，可用“仅看已选”核对，最后点击“导出已选 N 项”。
5. 可选择输出目录；未选择时输出到各 Word 文件所在目录。
6. 点击「导出已选 N 项」。窗口支持最大化，默认也会尽量显示更多扫描结果和明细内容。

输出文件默认命名为 `原文件名_表格.xlsx`；如果同名文件已存在，会自动追加 `_1`、`_2` 等后缀，避免覆盖。

每个 Word 在一次扫描中只打开解析一次，旧 `.doc` 只转换一次。表格和条款保留为本次扫描快照；导出复用快照并检查源文件大小及修改时间，源文件变化或移除后须重新扫描。

扫描使用「自定义符号…」中的当前符号集，并按每个 Word 实际检测到的完整章节路径汇总；不同文件可以选择不同章节。表格同一单元格内有多条带符号参数时，会按符号条款分别导出，同时保留对应续行和同行序号、名称等上下文。可勾选「条款内容中保留符号」，不勾选则符号只出现在符号列。每个选中符号章节的 Word 生成一个 `原文件名_指标参数.xlsx`。详见使用教程第七章。

## 拖拽填入开评标表

扫描并勾选来源表格，点击「填入开评标表…」，选择开评标 `.xlsx` / `.xlsm`。左边显示提取的原表，右边显示目标工作表的单元格和合并结构。窗口支持标题栏最大化及“最大化”按钮，F11 切换全屏、Esc 退出全屏。左右表格可独立使用 Ctrl＋鼠标滚轮或放大镜按钮缩放（50%～250%）；点击百分比恢复 100%，仅影响预览，不修改 Excel 的行高、列宽或字体。

1. 左边选择来源表，右边选择工作表。
2. 在左表单击选择单元格，或从未选中的单元格按住鼠标框选区域；Shift + 点击可扩大选区。
3. 从已选区域按住拖到右表，松开后显示蓝色待填入内容。区域以拖到的格为起点依次填入，来源保持不变。选中单元格可在下方查看全文。
4. 拖错可「撤销」「重做」或「清空预览」。切换工作表不会丢失已拖放的内容，可一次填写多张工作表。
5. 点击「填入并另存」，生成与预览相同的内容。原模板不覆盖，输出重名时自动编号。

Word 表格中的自动编号会按文档顺序还原，普通数字、中文编号、圈号、字母、罗马数字、项目符号及常见样式继承编号保留在扫描快照中，预览、拖放和导出复用同一份带编号的文字。

来源合并格只传递一次内容，不重复复制分值。多段文字落入同一个目标合并格时按原顺序合并说明；多个独立分值落入同一合并格时提示冲突。空白来源不清除模板内容。目标公式、数组公式及受保护工作表不能被覆盖。

「记住拖放位置…」保存位置对应关系，下次通过「复用拖放位置…」读取新项目的来源内容并形成预览；来源表结构或目标合并布局变化时会提示重新拖放，不会填入上次项目的旧内容。

「自动匹配…」保留按名称匹配、来源列与目标列手动对应、评分组合并和配置复用等辅助功能。点击「应用到右侧预览」后统一在拖放界面确认。

右表支持排版：选中单元格所在行，或拖动行号多选，也可点击、拖动列字母多选整列（Shift + 点击扩展，跨列标题合并不会被带入选区），然后点击「自动行高」；其他操作集中在「编辑表格」和右键菜单。未选择右表时，「自动行高」处理本表已拖入内容的行；按模板列宽、字体和合并区域计算，开启对应单元格的自动换行。双击单元格或按 F2 可直接编辑单元格文字（支持多行，留空清除，数字按数值写入，公式格不覆盖，编辑窗口可一键放大到屏幕 80%）；「放大表格」可把整个右表弹出为独立窗口编辑、自由调整大小，还原时嵌回原位。菜单支持编辑单元格、清空所选内容（批量清空选区，公式格跳过）、设置行高、删除所选行、合并/拆分单元格、上方/下方插入行、左侧/右侧插入列、删除空行；也可直接拖动行号或列标题边界调整行高列宽。删除空行会保留其他列有值、有公式及跨行合并的行；删除所选行则删除选中整行及内容。插入行继承相邻行样式，不复制正文与公式；合并文字按原顺序拼接，拆分后内容留在左上格，公式和多个分值不会被静默合并。修改均可预览、撤销、重做，点击「填入并另存」统一保存；也可以只排版不填内容。保存设置包含结构编辑和排版步骤，复用时从原模板按顺序读取新项目内容，失败会恢复原预览。

排版直接读写 `.xlsx` / `.xlsm`，不需要启动 WPS/Excel。增删行列会同步调整普通 A1 公式（外部引用只移动其中的本地单元格）、合计、打印范围、常规数据校验，以及图表引用、数据透视表区域、批注和浮动按钮的锚点；插入点落在数据透视表区域内、删除批注或图形所在行、含列表或 ActiveX 控件等无法可靠移动的结构会明确拒绝，仍可调整行高。原模板始终保留。扫描进度按已完成的读取、提取表格、提取条款和核验阶段推进，导出在实际写入后推进；读取模板等未知耗时操作显示循环动画，保存工作簿在原子提交成功后才显示完成。

结果使用 `_商务技术评审` 后缀。仅写入预览中的单元格并设置打开后重算，保留模板的行高、列宽、样式、合并、打印设置、其他工作表及宏。表格画布用于位置和内容预览，不是 Excel 的分页打印预览；长内容在画布中截断显示但写入保留全文。

## 从招标文件导入项目信息

点击「导入招标文件」选择招标 `.doc` / `.docx`，程序会识别常见字段并填入规则表。读取 `.doc` 需要本机安装 Microsoft Word 或兼容的 WPS Writer。
模板文件中可使用 `[项目名称]`、`[项目编号]`、`[标的名称]`、`[采购人名称]`、`[采购人联系人]`、`[采购人电话]`、`[开标时间]`、`[开标日期]`、`[招标公告日期]`、`[开标地点]`、`[报名人数]`、`[采购人地址]` 等占位符。未识别字段仍会生成空白规则，但不会删除模板占位符。

导入后显示已识别项数；「更多 → 查看项目信息来源」列出直接识别、推断、缺失、冲突及原文位置。多个不同候选值的字段留空，核对后手动填写。引用文本（例如“详见第8章”）不会抢占后面的有效开标值。

## 原文本预设

点击规则区右上角「预设」会打开多选下拉面板。勾选一项或多项后点击「添加所选」，程序会将尚不存在的预设加入规则表的原文本列。

点击「管理预设」可新增、重命名、删除并保存预设；初始内置的 12 个项目字段也可以自由修改。预设保存在当前用户的程序设置中，下次启动时继续使用。

## 分发说明

- 当前打包产物为 Windows 64 位程序，基于 Python 3.14，建议在 Windows 10/11 64 位系统运行。
- 未签名 exe 在新电脑首次运行时可能触发 SmartScreen 提示；这是未签名程序的常见现象，代码签名证书可作为后续根治方案。
- 如果通过网络下载 zip，Windows 可能给文件加 Mark-of-the-Web。遇到拦截时，可先右键 zip → 属性 → 勾选“解除锁定”，再解压运行。
- 建议解压到普通本地目录，例如桌面或文档目录，避免路径过深、网络盘、受保护系统目录。
- 替换 `.doc` / `.xls` / `.ppt` 时自动先转为 `.docx` / `.xlsx` / `.pptx`，进度和结果会提示转换，原文件保留。输出重名时自动编号，转换失败不会继续替换该文件，也不会影响其他文件。
- 绿色分发包不携带 LibreOffice，旧格式转换优先调用本机 WPS，其次尝试 Microsoft Office，均不可用时再查找本机 LibreOffice。新格式直接由 Python 库处理。
- WPS 需要提供可用的 COM 自动化组件；调用失败时会提示修复组件或手动另存为新版格式。转换可能改变排版，旧格式宏不会保留，请核对输出。
- `python build.py` 生成 `dist/replace-simple-v版本号-portable.zip`，打包电脑无需安装 LibreOffice。完整解压运行，无需额外的 `converter` 目录。
- 程序遇到未捕获异常时，会弹窗提示并写入日志：`%LOCALAPPDATA%\replace-simple\error.log`。

## 开发提示

- 测试：`python -m pytest tests`
- 打包前建议清理旧的 `build/`、`dist/`，`build.py --clean` 已会重新生成 PyInstaller 分析结果。
- 每次发布前在 `app_info.py` 中更新 `APP_VERSION`、`APP_RELEASE_DATE`，并把本次更新说明添加到 `APP_CHANGELOG` 首位。
- `python build.py` 会校验当前版本是否有更新说明，并同步更新窗口标题、软件内版本信息、Windows EXE 文件属性和压缩包文件名。

源码版新增：右表可拖动行号、列字母之间的边界调整行高和列宽，支持撤销、设置复用及另存。编辑菜单支持左侧／右侧插入列；插入行列支持共享公式展开和数组公式范围移动。预览按屏幕 DPI、模板字体、对齐、换行和边框显示。程序内输入及消息弹窗统一为应用样式，文件选择仍使用系统文件选择器。
